# LUMEN 1.7.2 — Three-Lamp Rule

- Основная механика изменена: каждое нажатие переключает ровно 3 лампы.
- Для центральных колонок меняются: выбранная + слева + справа.
- На левом/правом краю меняются: выбранная + соседняя внутрь + одна вертикальная соседняя лампа (внизу — вверх). Поэтому на краях также всегда ровно 3, без скрытого переноса через поле.
- Генератор уровней использует ту же функцию переключения, поэтому сгенерированные стартовые позиции гарантированно имеют решение: они создаются из выигрышного состояния последовательностью допустимых ходов.
- Обучение обновлено под правило «3 лампы».
- Автосохранение из 1.7.1 сохранено.
