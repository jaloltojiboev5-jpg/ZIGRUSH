# ZIGRUSH 3.1 — Record Rush

- Removed collectible stars and star bank from gameplay/UI.
- Game goal is now distance + personal best.
- Difficulty ramps faster: speed, obstacle density and tree gates increase with distance.
- Rewarded-video continue button added after a crash, limited to once per run.
- Uses Google's Android test rewarded ad unit for development; production AdMob IDs must replace test IDs before store release.
- After rewarded continue, nearby obstacles are cleared and skier receives ~2.2 seconds of collision protection.
- Pause remains available.
- Launcher icon pipeline fixed: Capacitor's default adaptive icon XML is removed during CI and ZIGRUSH artwork is copied into launcher mipmaps.
